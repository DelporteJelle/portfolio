Tronk

A bot for multiplayer snake on a hexagonal grid, written for a competition.

TypeScript · Search
Repository → Play it → Write-up →
Two bots, one board — the moment before a head-on collision
What it is

Tronk is a competition where everyone writes a bot for a multiplayer snake game played on a hexagonal board. Bots take one move per tick, share the arena with the other bots, and lose the moment they run into a wall, a trail, or each other.

The interesting problem

Six neighbours instead of four sounds like a small change and isn't. The branching factor rises, familiar grid heuristics stop being admissible, and every move has to be returned inside a hard deadline — so the search has to be worth more than it costs on a board that only exists for a few hundred milliseconds. [EXPAND: what the actual deadline was]

How I solved it

Axial coordinates for the board, so neighbours are arithmetic rather than lookups. A flood fill each tick to score reachable space, and shallow lookahead that spends its budget where the opponents actually are — territory first, aggression only when the fill says the space is already won. [EXPAND: the one decision you'd defend in an interview]

What I'd do differently

The evaluation function was tuned by hand against a handful of matches, which is another way of saying it was tuned against my own habits. Self-play with recorded games would have found the weightings faster and less flatteringly. [EXPAND: what actually cost you the round]
